## Positioning

A training app built around low-friction logging, keeping the jump between working out, recording, and reviewing as light as possible.

## Key Decisions

1. Put fast logging and low cognitive load first, instead of piling on complex fitness analytics.
2. Avoided over-gamification — most fitness apps turn into maintenance fatigue over the long run.
3. Used a local-first data structure so it works long-term without an account system.

## Iteration

V1 basic workout logging → V2 calendar intensity view → V3 per-exercise progress and a workout timer.

## Built with

Claude Code, Codex, React Native, Figma · ~3–5 days (still iterating)

## If I rebuilt this

Adjust the training flow automatically from the user's behavior patterns instead of fixed templates.
