## Positioning

A roguelike that folds Texas Hold'em into UNO-style drafting: build your hand from cards drawn each round, then play no-limit poker against the AI.

## Key Decisions

1. Wired drafting into poker so odds-shaping starts before any bet — the hand has already shifted before you sit down.
2. Cut the messy item-card system — it watered down the psychological read that makes poker work.

## Iteration

V1 draft + poker core loop → V2 AI behavior tuning → V3 UI readability and pacing.

## Built with

Claude Code, ChatGPT, Figma · ~1–2 days

## If I rebuilt this

Add long-term meta progression so players gradually grow their own style.
